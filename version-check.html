📡 電波 / 神聖計劃 D2 Digivice

進入 Debug Mode 檢查版本方法：
只需按住 A + B 鍵 同時按下 Reset 並鬆開即可。
(部分機種一開始會出現黑畫面，試著按不同按鍵就會跳出版本畫面)
Simply hold down the A and B buttons simultaneously while pressing and releasing the reset button. (Note: Some devices may initially display a black screen, but you can simply press a few more buttons to check the version.)
主機版本 Debug 顯示 Code 備註說明
Ver 1 (011) [全黑屏] [Full Black Screen] 開機無字元直接全黑
Ver 2 (012) US．V2 存在高仿版本，需特別注意辨別
Ver 2.5 (0125) US．V2.5 透光外殼特殊版本

如何辨別真品和高仿 (To distinguish between genuine and bootleg):

  • * 只有 Ver 2 (012) 存在高仿 (Bootleg are all version 2)
  • 檢查外殼模具細節、按鈕手感及屏幕邊框印刷。正版零件邊緣整齊清晰。

🧭 D-Power

進入 Debug Mode 方法：

  • Ver 1 (031)：
    只需按住 左 + 下鍵 (Left + Down) 同時按下 Reset 並鬆開即可。
    Simply hold down the left and down buttons simultaneously while pressing and releasing the reset button.
  • Ver 2 & 3 (032 & 033X)：
    只需按住 左 + 右鍵 (Left + Right) 同時按下 Reset 並鬆開即可。
    Simply hold down the left and right buttons simultaneously while pressing and releasing the reset button.

⚠️ Difference between V3.00 & V3.01? (0330 和 0331 的差異)

中文說明：
由於 0330 (V3.00) 存在系統 Bug，會在遇到最後一張地圖的第二位 Boss 時死機。而在 0331 (V3.01) 版本中，此 Bug 已被修正。
* 0330 可以使用 Debug Mode 去繞過此 Bug 繼續遊玩。但使用此方法打敗該 Boss 後，會無法正常瀏覽角色數值，且無法在通關後繼續遊玩。

English:
In version 3.00, it has a bug that causes the game to freeze when encountering the second boss on the last map. This issue has been resolved in version 3.01. For v3.00, you can use the debug mode to beat that boss and continue playing. However, after using the debug mode to defeat the boss, you will no longer be able to access and view your character stats or play post-game.
